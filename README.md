# La Liga

## Integrantes
Eric Iborra Polo

## Tema
La Liga española de fútbol.

## Descripción
He creado una página web sencilla sobre La Liga. En ella presento información general, cuatro equipos de fútbol y una tabla con resultados de partidos.

## Archivos y páginas
- index.html: página principal.
- equipos.html: información de cuatro equipos.
- partidos.html: tabla con resultados de partidos.
- css/style.css: estilos y diseño de las páginas.
- js/script.js: función de JavaScript.

## Instrucciones para abrir index.html
1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Hacer doble clic en el archivo index.html.
4. La página se abrirá en el navegador.
